# V0.6 数据、图片、ZIP 与报告口径

版本 0.6.0 / code 6 / com.tradereview.app。生产 APK 不新增 INTERNET、读照片或广泛存储权限，不接云端 AI、行情或账户。

## 图片

通过 ACTION_OPEN_DOCUMENT 系统文件/照片入口由用户选择 JPEG、PNG 或 WebP；一次选一张，每笔最多 10 张，全库最多 10000 张。原图上限可设 5/10/20 MiB，默认 10；拒绝超过 4000 万像素。后台采样解码、按 JPEG EXIF 方向归一、透明背景转白，重新编码 JPEG 85，最长边 2048、存档单张至多 4 MiB。动图仅保留首帧；不是原始字节副本。存档不保留来源 URI、EXIF 位置或多余照片元数据。

attachments 用稳定 ID、交易 recordKey、分类、说明、SHA-256、字节数、像素、时间和排序关联；不把 Base64 塞进交易。文件名仅为 ID 与摘要组成的固定 ASCII 格式，App 私有目录不通过网络或内容提供器共享。缩略图/大图在后台读取，损坏/缺失有可见状态，允许删除损坏附件后从完整 ZIP 恢复。说明最多 200 字。

数据/文件生命周期共用进程内 Mutex。不可变图片先写临时文件、校验、同步文件、原子移动并 fsync 私有目录，之后才提交附件元数据。删除先提交记录/外键级联，再清理无引用文件；取消/崩溃造成的多余文件不会作为记录出现，下次启动按数据库引用清理。清理失败不把已经提交的恢复误报为回滚，可能延迟回收空间。正确的旧图片不会在恢复提交前删除。

## 完整 ZIP 格式 1

固定内容：data.json、manifest.json、images/ID-SHA256.jpg。data.json 是 schemaVersion 5、backupScope=with-attachment-files 的严格 JSON，包含全部十二表：原九表、附件、改善目标和图片设置。manifest.json 字段为 format=trade-review-full-backup、zipVersion=1、exportedAt、data、images。每个文件清单项含 path、bytes、sha256；图片元数据与清单及真实文件逐项一致。manifest 不包含自身摘要；数据文件含原有规范化完整性校验。摘要不是加密或数字签名。

ZIP 最多 256 MiB，解压实际总量最多 512 MiB，图片最多 4 MiB，数据 JSON 最多 16 MiB，清单最多 4 MiB，文件最多 10002。检查中央目录及流式实际条目、重复名、实际字节计数、CRC、SHA-256、严格 UTF-8/JSON、尺寸/解码及引用。只允许上述路径，拒绝目录、绝对路径、回退、反斜杠、未知条目、重复字段、超限和不支持的压缩。即使伪造声明长度，流式计数仍受上限约束。限制可能使非常大的图库无法一次备份，会明确失败，绝不静默遗漏。

导出前验证每张图片存在、可读和可解码；写出时再次核对实际字节与摘要。恢复先在私有临时目录验证全部数据和文件，再预览数量、冲突及范围；确认后重新校验。新文件先发布，十二表单 Room 事务后再清理。SQL、空间或校验失败时数据库回滚、旧正确文件保留；尚未引用的新文件回收。预览后十二表任何变化都会拒绝旧确认并要求重新预览。

覆盖替换全部数据/目标/图片；合并按 recordKey 保留冲突交易及其本地证据，不拼接不一致的截图。相同交易可以补入新的附件 ID，本地同 ID 元数据优先；合并超过每笔/总数限制整体拒绝。目标冲突按稳定 ID 保留本地规则与归档历史，图片大小政策保留本地设置。图片文件不会被任意同名替换。

JSON schemaVersion 5 的公开单文件导出明确为 structured-data-only，不带图片引用/文件，但带目标与图片政策；兼容 V0.2/V0.3/V0.4/V0.5 格式 1/2/3/4（含旧 ART 校验）。恢复预览明确范围；JSON 覆盖确认明确会清理本机图片。从 ZIP 抽取的 with-attachment-files JSON 不允许单独恢复。CSV 与旧 JSON 导出仍保留。备份均明文，请由用户选择可信存放位置。

## 数据库与报告

Room 6 只新增 attachments（recordKey 外键级联删除）、review_goals、evidence_settings；正式 MIGRATION_5_6 保留 v1→v6 链、旧专业/风险和所有交易事实，不 destructive migration。v6 schema 以实际 KSP 产物为准。报告实时派生，不保存重复金额结果。

周报周一至周日，月报自然月，全部日期基于 LocalDate/epochDay。当前周期只统计截至今天，上一周期按完整范围比较并注明长度可能不同。金额与 R 按币种分别计算，原 V0.5 权威净盈亏/有效风险口径保持不变。未知风险不计 0R，R 显示有效样本；胜率分母包括持平。计划内外比例分母仅明确状态，未知单列。纪律只计显式勾选标签，不把未提供当作守规；风险违规统计仍按曾触发的交易及可执行检查分母。总结只引用实际笔数/标签/前期差值，少于 20 提示不稳定，不预测收益或推断因果。

目标可并行，每周/月从所选周期起递推，保存后的规则保持稳定，调整请新建；归档保留规则与历史，并截断归档日之后的数据。历史从真实记录重新计算，后续补录/修正旧交易会更新相应历史，而目标本身不改交易。错误次数和违规次数是上限；复盘比例、计划比例和复盘天数是下限。计划比例仅明确计划内/外，风险次数仅可执行检查，零样本显示不可计算。盘后天数分母为周期已过自然日，不是交易日，缺失不填 0 分；比例显示舍入两位，达标判断使用更高精度。自定义文字目标完全不自动量化。报告预览前十目标，管理页可查看全部。

## 签名与实际验证

V0.3 pin 不变。最新 main 实际日志仍未配置固定 Secrets，本轮不生成/读取/替换私钥。所有者使用既有 V0.3 keystore 配置四项 TRADE_REVIEW_KEYSTORE_BASE64 / TRADE_REVIEW_KEYSTORE_PASSWORD / TRADE_REVIEW_KEY_ALIAS / TRADE_REVIEW_KEY_PASSWORD 和 TRADE_REVIEW_UPGRADE_CERT_SHA256 变量；具体安全步骤沿用 V05-CALCULATIONS-AND-UPGRADES.md。仅完整配置并同时匹配原 pin/变量、单 signer 和完整 CI 才能交付固定包；否则临时包不能保证覆盖升级，不在手机卸载或删数据。

验证记录见 V06-VALIDATION.md。选择器测试通过测试 Registry 注入真实 content URI、确认 ACTION_OPEN_DOCUMENT/MIME；图片由只在测试 APK 的 provider 提供合成图片，实际走 ContentResolver、Android 解码/压缩与私有文件。低空间通过注入容量模拟，不真的填满设备。截图为真实 API 29 模拟器窗口，不是手机实测。
