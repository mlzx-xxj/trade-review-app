# V0.7 真机验收步骤（尚未执行）

以下延续 V0.6 未完成的真机选择器、图片、恢复、键盘和升级清单，并增加 OCR。开发 CI 使用 API 29 模拟器和合成数据；不能代替这些手机检查。请记录手机型号、Android 版本、APK SHA/证书、每项结果和问题复现步骤。用合成截图/少量测试交易，避免在含重要数据的设备进行覆盖恢复。

1. 在 Release 查看 SIGNING.txt、版本 0.7.0/code 7、SHA256SUMS；下载 APK 校验摘要。未配置固定签名时不能保证覆盖旧版，不要直接卸载含数据的旧 App；先在旧版完整 ZIP/JSON 备份并保留可读副本，可用备用设备验收。
2. 固定签名已配置且两版证书相同后，在保有 V0.6 少量测试交易/目标/图片/设置的设备安装 V0.7；应覆盖成功且全部数据仍在。若证书不同，记录安装拒绝，不将其当数据库迁移失败，也不清数据。
3. 首次启动前开启飞行模式。通过系统文件选择一张本地合成中英文成交截图；应后台识别日期、rb2701、多空、价格/手数、负净盈亏，无下载模型或联网提示。图库中仅云端的未下载文件需先变成本地文件，这不代表 App 联网。
4. 从已有附件发起识别，原交易及图片不变。关闭/旋转、取消识别；原始识别文本不进入导出备份。把其中一条只保存为 OCR 草稿，退出重开，字段恢复且全部人工核实勾选清空。
5. 对清晰的带编号/日期分段多笔成交截图，选择一条，逐项核实字段，修改金额应取消该项与已平仓确认。缺日期/币种/方向、冲突、委托/持仓/浮盈/K线图不能直接保存成交；可存草稿。明确已实现毛盈亏时先人工确定最终净值。
6. 核实所有字段和已平仓净盈亏后创建，勾选保留证据。列表/首页/统计即时刷新，净金额准确、原快捷草稿保留、专业字段/附件可查看。重复候选先弹出原记录，未确认不新增，确认仍新增不删除原记录；风险越限仍走原确认。
7. 添加四类截图、改说明、缩略图/大图左右切换、删除附件；每笔十张上限。删除测试交易需确认并清理关联图片。选择损坏或权限已失效文件应显示错误，不损坏原记录；查看厂家文件选择器、旋转照片与低内存表现。
8. 设置最低样本/类别，建立少量合成历史交易与对照期，核对洞察的分母、币种/R、未知状态、日期、可展开公式及真实明细。空记录/低样本显示暂无足够记录；关闭类别停止相关派生提示。
9. 在智能洞察与每日计划进入同日期盘前清单，检查历史错误/规则/生效目标/昨日漏复盘依据。勾选、重开保持状态；添加、勾选、归档个人项目，历史仍保留。关闭自动提醒保留历史，交易和 planSaved 不自动变化。
10. 周报/月报切换跨年、月初、闰月历史周期，复盘洞察可查看真实记录；币种金额分开，R 有效样本明确，当前周期/前期长度说明存在，未知纪律不当遵守。
11. 在设置用 SAF 保存完整 ZIP 到本机目录，确认照片/目标/盘前检查/OCR 草稿/规则全部纳入。以测试数据预览并二次确认合并/覆盖，重开图片仍可读取；导入旧 V0.2–V0.6 JSON 明确不含图片。取消确认不改变本地数据。
12. 用损坏/不完整备份副本尝试导入，应拒绝且全部原数据可读。切换深色、两种盈亏配色，小屏幕与数字键盘下检查 OCR/目标/交易保存按钮可见，系统返回行为正确，CSV 中文/逗号/换行正常。

验收结果目前均为“待用户真机执行”。若仅临时签名，长期覆盖升级仍是未完成项；优先配置已有固定密钥，再验证真实升级，而非重生成密钥。
