# V2.1 界面规范

范围是呈现与交互，不改变成交事实或计算口径。新增成交仍然只需代码、价格、数量；可选项默认折叠，保存不增加确认。

| 规范 | 浅色 | 深色 |
|---|---|---|
| 页面背景 | `#F3F5F9` | `#0F1622` |
| 内容表面 | `#FFFFFF` | `#182230` |
| 主文字 | `#17243A` | `#E5EBF5` |
| 辅助文字 | `#53637B` | `#ADBAD0` |
| 主色 | `#304C75` | `#B4CBF7` |
| 盈利 | `#AF273C` | `#FFB4B0` |
| 亏损 | `#087044` | `#80D5AF` |

主要及辅助文字对内容表面的 sRGB 对比度：浅色 15.56:1、6.11:1；深色 13.38:1、8.17:1。盈亏文字均超过 6:1。同时显示金额符号、亏损负号，以及盈利／亏损／持平状态，颜色不能成为唯一依据。未知费用、保证金和净盈亏保留明确的待估算文字。

页面标题 24sp、模块标题 18sp、关键数据 24sp、输入与正文 16sp、辅助说明 12–14sp。金额使用等宽数字特性；数值不省略关键尾数，长金额在可用宽度中缩放到可读下限后换行。人民币显示按 HALF_UP 四舍五入至两位小数，保持原内部精度与存储值。

间距使用 4／8／12／16／24dp，内容卡片 16dp 圆角，输入与分段控件 12dp 圆角。主要交互区域至少 48dp，底部保存区域至少 52dp，继续应用系统安全区及 IME 边距。

交易表单按市场、品种、方向、价格与数量排列；自动费用及保证金保持在保存按钮附近。品种选择入口放进代码字段，减少单独按钮行。持仓卡片依次显示品种身份、方向、数量及均价、已实现盈亏及资金信息，手续费与持仓成本放入次级行。首次开仓日期在详情查看；已设置的止盈止损在卡片底部弱化显示。不展示实时或浮动盈亏。

组件只抽取共用的分段选择、金额文字、字段、状态标签、数据网格与空状态；不进行架构重写。细节以实际 API 29／35 截图和体验报告为准。
