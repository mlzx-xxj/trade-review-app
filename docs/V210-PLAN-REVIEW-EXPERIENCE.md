本报告随真实模拟器验证更新。当前是开发记录，尚未完成的新测试与截图不标记为通过。

基准为已合并 PR #18 的 main `2249e7a5330eb11684499394270034dc7cf2b4c7`；[合并后的完整 CI](https://github.com/mlzx-xxj/trade-review-app/actions/runs/39033445507) 已成功。正式版本仍为 2.0.0 / code22，本轮不制作正式 V2.1 安装升级包，也不发布 Stable。

本轮仅处理 V200Review.kt、V200AccountsStats.kt 的账户部分及一个共用编辑布局。首页、成交录入、持仓卡片、统计和图表保持原状。资金流水编辑对象改用可恢复的稳定 ID 保存，以便检查横竖屏重建后仍编辑同一记录。

设计上将计划和复盘切换固定在页面顶部，区分计划日期、品种、策略及持仓状态；把长文字提前，使用可滚动的多行文本区域。编辑页沿用成交录入已经验证的系统安全区及输入法布局，保存按钮独立固定。只读成交事实与用户复盘价位、文字分区。账户以实际盈亏和已记录费用为先，资金流动保持中性色，持仓成本、参考保证金及参考现金明确标注其含义。

## 验证方法

基线生产代码与上述 main 相同，只新增 UI 测试及测试依赖。实际 MainActivity 在 API29/API35、360dp/320dp、字体1.0/1.3、浅深色四组配置中运行同一操作路径，再由外部 runner 强制停止后以新进程读取。

所有成交、计划、复盘、期初资金和出入金均从页面填写保存；测试只预置空账本和一条命名明确的合成策略。系统日期选择器始终选同一组合成日期，避免前后构建跨北京时间午夜改变数据。日期选择的两次点击与普通录入点击分开记录，输入字段不按键盘逐键计数；必要滚动按实际执行的滚动命令记录。

独立 Python Decimal 校验器核对费用、FIFO、剩余数量、已实现净盈亏和参考现金；前后交易事实逐项比较。未知费用、净盈亏、保证金保持 null。保存按钮记录实际输入法与无障碍屏幕边界；长文字自身滚动不误记为关键金额溢出。原始 PNG 不重绘、裁剪或合成。
