# V1.0 实施与发布边界

从已合并 V0.8 PR #8 的 main `7f8c60ea9394f179ed8da48241ab46581d2b6238` 创建 `codex/v100-release`。沿用原工程、依赖、targetSdk 35、Room 7、JSON 6、ZIP 1，保留完整迁移链及全部业务功能。取消 V0.9 成交 CSV 导入、映射与自动配对，CSV 导出保留。

1. 优化首页层级、底部短标签、直接盘前/盘后入口、48dp 操作、图表换行与评分可访问性；完善静态自适应/单色图标及深色启动背景。
2. 可跳过、可从设置重开的本机引导；不创建交易。更新用户通过包更新时间或真实业务记录识别，不反复弹完整引导。
3. 完整 ZIP 主入口、明文隐私说明、设备本地备份提醒与延后。真实写出后回读 SHA-256；只有写入成功才记录，不能回读与验证成功明确分开。
4. 同工程独立 RC buildType；正式 Release 使用原 V0.3 密钥，禁止随机 Debug 签名回退，证书/权限/版本/模型/来源二次校验。
5. 全 JVM、Lint、API29/35 迁移/恢复/OCR/大数据/完整操作链；额外实际安装交付的不可调试 RC 并重启验证；材料具备时安装真实旧固定签名 APK 后 install -r 验证数据保留。
6. 更新真实验证记录、手机验收与签名指南，独立 PR，不自动合并。

稳定签名及用户真机验收是正式稳定发布门槛。缺少原私钥不能自行替换，其他开发测试继续；预发布 RC 与固定签名 Release 候选包都不得冒充已完成手机验收。
