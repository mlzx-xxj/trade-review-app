# V2.0 成交录入实测

本轮分支 `codex/v200-fast-entry`，基于 main `b5cfddb210e5893a3554ee4978f0204366b35f3f`。正式版本仍为2.0.0，versionCode递增21，RC为2.0.0-rc.2。下方目前是测试口径和预期；完整Android CI、真实操作计数及截图验证后再补实际结果，不能以代码或预期冒充通过。

## 修改范围与数据口径

- 普通录入去掉日期/时间/秒/序号/夜盘/逐笔参数确认；期货四个买卖开平按钮，股票买卖，价格/数量使用数字键盘。策略、名称、止盈止损和计划放在可选区。
- 新记录自然日期来自设备时钟转换后的北京时间；全局保存顺序由Repository分配，编辑保留位置。同分钟/钟表回拨不要求顺序弹窗。旧记录继续使用旧排序，不修改其原日期、费用、ID或审计。
- 重用Room v8字段与原迁移链，没有表/列变化。新记录的费用来源 `auto` 同时明确采用保存顺序；旧 `actual`/`rule` 语义不变。JSON7/ZIP1结构不变，旧备份继续校验恢复；老版本不识别新枚举时应拒绝，不承诺新备份回灌旧App。
- 新股票综合费用固定买万一/卖万六，不加0.01、税或最低佣金；旧账户配置及旧费率快照保留，不强改历史费用。
- 新期货按每手或成交额计算基础费，平仓按实际FIFO匹配的开仓自然日期分配平今/平昨；整笔合计后仅加0.01，再HALF_UP到分。分配开仓/平仓费用沿用原精确守恒算法，不重复扣费。
- 开仓显示该笔预计新增保证金；平仓显示同合约剩余持仓按原开仓参考参数合计的预计占用，不当作新增，也不推算真实追保。
- 历史编辑/删除仍预览二次确认，重新配对并保留审计。若匹配改变了后续自动平仓费用，只按那笔自己的原快照重算并审计，不使用新目录费率；数量不足、失联复盘、冲突恢复整体拒绝。

## 官方离线参考与限制

来源摘录、核实日期、原始文件SHA、25个参考品种及参考合约见 [FUTURES-20261015.json](reference/FUTURES-20261015.json)。2026-10-15实际读取SHFE合约配置、2026-10-14结算/交易参数及官网收费XLSX，含SHFE/INE联合公开数据。合约乘数使用公开product_config；普通基础费采用收费表，平今系数按官网说明相乘；保证金是明确参考合约当日投机多头比例。品种级复用是离线简化，不追踪不同月份/交割月上调/临时优惠，不代表期货公司实际扣费或保证金。

已核实25个：铜、国际铜、铝、锌、铅、镍、锡、氧化铝、铸造铝合金、黄金、白银、螺纹钢、线材、热卷、不锈钢、原油、低硫燃料油、燃料油、沥青、丁二烯橡胶、天然橡胶、20号胶、纸浆、胶版印刷纸、欧线集运。其余19个名称保留但参数未核实，不能据此编造成交。DCE/CZCE/CFFEX读页返回503/412，GFEX未返回参数，INE收费页安全验证未绕过。不能拿第三方估计或过期公告假称官方当前标准。
