# 数据与备份兼容

Room 保持 v7，未增加表或列；正式 v1→v7 迁移及十六张业务表保持原样，不使用 destructive migration。交易 recordKey、历史净盈亏、风险快照及所有财务统计公式不变。JSON schema 6 与 ZIP 容器 1 保持，支持既有 V0.2–V0.8 受支持格式。

完整 ZIP 保存结构化业务数据、全部设置与附件实体/文件/校验清单。JSON 不包含截图文件，界面明确标注。既有大小/数量限制、路径穿越/重复路径/炸弹防护、预览、冲突计数、二次确认、事务和文件协调回滚保留。

导出包装器统计真正写出的字节数和 SHA-256，输出流关闭成功后才尝试 SAF 回读。同字节数内容损坏、截断、超长均拒绝记为备份成功。系统提供者无法回读时明确显示“已写出，未验证”，不会更新“上次校验通过”时间；打开选择器、取消、输出失败均不推进任何成功时间。CSV 导出不冒充备份。

新手引导、上次本机导出/校验时间、提醒开关及延后期限属于设备操作元数据，保存在独立本地 SharedPreferences；不随业务恢复导入。不能把另一台手机的时间当作本机已备份证明。业务设置仍全部包含在原完整备份。七天建议按已校验完整 ZIP 计算，可关闭或延后，不自动上传。

ZIP/JSON 是明文。SHA-256 检测意外损坏，不提供加密或可信签名认证。请选择安全位置，卸载/清除数据/更换签名安装前自行确认可用完整 ZIP。RC 包与原包数据隔离，需要用户明确选择备份文件恢复，应用不自动访问旧包数据。
