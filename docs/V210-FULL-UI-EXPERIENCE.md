# V2.1 第一批：首页、统计与图表

本批只改首页、统计和图表的呈现。基准是 PR #17 合并后的 main `6776d4d4c437c71fb3117ecf35f4cc22abfe8932`；成交录入、持仓卡片、复盘和账户页面的设计不重做。正式版本仍为 `2.0.0 / versionCode 22`，没有升级或发布 Stable。

## 设计与数据边界

沿用已有蓝灰主题和 4/8/12/16/24dp 间距；主要触控区域至少 48dp。盈利用红、亏损用绿，同时提供正负或文字说明；多空仍使用独立的蓝灰方向标签。金额沿用原有 HALF_UP 两位小数显示，原始 BigDecimal 和持久化值不变。

- 首页：本周金额为第一层；本月和历史累计并列作为第二层。最近七日可横向滑动，默认滚到今天；月历按需展开。持仓按账户展示数量摘要，复用已验收的原持仓卡片；宽屏并排展示三组金额和统计筛选，减少横屏纵向占用。最近三笔成交进入原成交详情，交易和复盘入口各直接切换对应页面。
- 统计：周/月、市场和日期范围集中在顶部。已实现净盈亏、有效样本/全部平仓、胜率、盈利/亏损/持平笔数和单笔平均值按层次呈现。已知样本与待估算样本说明保留。
- 图表：每日图保留原有金额轴算法、52dp 日期单元和横向滚动；刻度宽度按实际字体测量，零轴加重，正负柱分方向。持平、无平仓、待估算用不同形状与文字区分。品种分布统一金额轴，金额直接显示在对应品种旁；端点和零刻度分行，减少重叠。点选和无障碍操作仍打开精确金额。

没有修改 FIFO、费率、保证金、统计周期与有效样本公式、Room、备份格式、版本、包名、签名或发布流程。首页完整合计含未知费用时保持未知；统计沿用原有“仅汇总已知样本”的规则，两者不能混为一谈。
