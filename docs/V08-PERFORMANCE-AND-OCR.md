# V0.8 可复现性能与离线 OCR 评估

数据来自 [第四轮 Actions 38243865978](https://github.com/mlzx-xxj/trade-review-app/actions/runs/38243865978) 的真实 API29/35 模拟器；94项测试均通过，但随后进程探针准备失败，因此该运行不是完整发布成功。最终运行会再次生成 Release 的 PERFORMANCE-AND-OCR.json、CI-RESULTS.txt，数值可能随共享宿主波动。所有记录/图片为合成数据。

## 测量方法

PerformanceBaselineTest 固定2026-01-31、1000/5000/10000笔及独立币种，warmup1次、正式3次，以 elapsedRealtimeNanos 壁钟中位数为主，原始 samples/min/max 在 docs/benchmarks。冻结 main 9bc2dab 的参考算法仅用于测试；同一进程、相同输入测参考与新版，逐结果相等校验在计时之外。没有以宿主差异或不同Android运行时冒充优化收益。

复现：Actions → Android CI → Run workflow → codex/v08-stability，保持可选签名输入空白；或者具备SDK/KVM的测试机执行 `V08_STABILITY_PROBES=true bash scripts/run-device-tests.sh`。专用真实Activity夹具/进程探针只允许一次性模拟器，不能在个人设备执行。

明确收益在大型连续亏损段、缩略图和索引查找。完整统计只减少重复排序、保持展示顺序及所有财务结果；API29万笔本轮慢约6.5%，1000亏损段也慢，不宣称全面提速。小幅差异可能来自JIT、GC、宿主噪声，只有三次样本，不能推断手机性能。

图片参考路径保留原逐次解码/SHA格式化方式，新路径8 MiB上限、命中仍计算SHA，十张真实合成图共约84 KiB，缓存像素1,152,000 bytes/30次命中。SQL基准只有元数据、查询结果及EXPLAIN索引校验，不能当作万张真实图的内存/图库测试。

真实MainActivity包含1000/5000/10000笔列表滚至指定项再回顶并等待idle，以及日历切月。API29列表中位数分别317.709/264.998/246.231 ms，API35为380.758/366.868/322.169 ms；以原始activity JSON为准。这不是帧率/jank测量，也没有旧版Activity前后对照。Room万笔读取269.841/311.506 ms，JSON万笔往返3595.125/6096.581 ms，结构化ZIP写1442.155/2258.786、读2359.514/4229.889 ms；此ZIP约172 KiB不含照片，与真实图片ZIP回归分开。

CPU统计在Dispatchers.Default、图片/文件/数据库导入在IO。统计范围标记阻止旧币种/筛选的派生结果误显示，不改变权威历史记录。进程启动测量使用am start -W、此前测试已暖OS缓存；温启动可复用或创建Activity，不是端到端数据就绪时间，也不是手机冷启动。

## APK 体积

第三轮实际APK56,041,946 bytes，V0.7为63,608,733，减少7,566,787（约11.9%）。仅将扩展图标整库替换为同版本core及四个原官方矢量，并将IDE inspector设为可选；许可证保留。全部arm64-v8a/armeabi-v7a/x86/x86_64与Chinese/Latin四个OCR模型仍在APK，构建/发布检查会拒绝缺模型。最终APK精确大小/SHA以Release为准。

## OCR 适用范围

OcrEvaluationTest 使用真实随APK打包的中文/Latin识别器；API35 AOSP无Play Services、无App网络权限。九张合成图包括中英数字清晰图、半分辨率、轻模糊、实体旋转+EXIF、多筆已平仓、委托、持仓浮盈、K线。逐字段严格规范化比较，不把缺失算正确；原始样本记录expected/correct/missing/wrong/extra以及用时，parser安全性和人工确认另有回归。

第三轮77个标注字段：API29正确73、漏3、错1；API35正确74、漏2、错1。第四轮相同：API29正确率73/77=94.81%、漏识率3/77=3.90%、误字段1/77=1.30%；API35正确率74/77=96.10%、漏识率2/77=2.60%、误字段1/77=1.30%，两API额外字段均0。最终运行会独立报告。未标注的额外字段另计，不隐藏误识别；三个不安全类别无可保存候选。字段已识别仍必须人工核实，K线/委托/持仓不能臆造成交信息，图片或原OCR全文不会自动变成历史交易。有限合成集不能代表券商全部布局，也不承诺100%。

原始前后数据保存在 [benchmarks](benchmarks)：v08-before-*是完整第三轮优化前数据，v08-after-*是第四轮同进程参考/新路径与实际设备结果。正式最终运行数据在Release自动报告；没有执行真实个人截图或真机评估。API36为可选、此次未执行。低内存/厂家键盘/文件提供器、大批真实照片仍需按手机清单验证。
