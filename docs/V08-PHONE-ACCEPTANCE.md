# V0.8 仅用安卓手机验收（尚未执行）

所有项目目前为待手机执行；API 29/35 模拟器、合成 OCR 和进程重启不代替真实手机。记录型号、Android 版本、字体大小、APK 摘要/证书及每项结果。使用合成截图和测试记录，保留旧 App 可读的完整 ZIP 副本，优先用备用设备。

1. 在 PR 下载页登录有仓库权限的 GitHub 账号。下载 APK、SIGNING.txt、SHA256SUMS.txt、PUBLICATION-CHECK.txt、CI-RESULTS.txt。核对 0.8.0/code 8/com.tradereview.app。临时包明确不能保证覆盖旧包或未来升级；不要直接卸载含数据的应用。
2. 需要长期升级时，由你按 V08-PHONE-SIGNING.md 在可信手机准备原 V0.3 材料并配置 GitHub 网页 Secrets/公开 pin，不发送私密材料给 Codex。等待完整新构建，确认 actual certificate 和 upgradeVerified，再选择新固定包。
3. 只有旧/新两个 APK 都真正匹配原 V0.3 pin 时，才在测试设备做原身份覆盖安装；检查原交易、风险历史、标签、设置、日志、草稿、目标和图片保留。缺原密钥/旧固定包时标记“未执行”，不能用临时签名的同版本重启冒充。
4. 首次启动前开启飞行模式。选择本地已下载的合成中英文成交图，核对无需下载模型；打开已有附件识别，原记录和图不变。云相册仅云端文件先变成本地，这不代表 App 联网。
5. 核对日期、品种/合约、方向、币种、负号、小数、价格、数量、费用和最终净已实现盈亏。试旋转、模糊、低分辨率、多笔、委托/持仓/浮盈/K线图；缺失/冲突留待确认，不直接保存。逐字段确认后才创建，尝试重复记录并查看原记录。
6. OCR 中取消、退到后台、系统返回、重开 App；原始全文不进备份、未核实候选不成交易，OCR 草稿恢复后重新确认。故意选损坏/无法访问图片，错误要明确且历史不变。
7. 快捷金额空/0 被拒绝，持平需明确选择；复制上一笔清空结果，保存继续、编辑历史专业字段和风险违规确认正常。用大字体、小屏/横竖屏与真实数字键盘验证保存按钮完整可见，检查保存/失败反馈。
8. 收藏品种搜索时，键盘下首个结果可见；IME 搜索收键盘，清除恢复市场选择。新增/改名/隐藏标签后检查原交易、统计、导出保持关联。
9. 添加十张不同合成截图，说明/大图/左右切换、反复返回缩略图、后台切换后仍可读。原 URI 移动/权限失效不能破坏已经复制的图。删除测试附件/交易需确认并清理相关文件，其他图保持完整。
10. 切换币种/组合筛选、月份/热力图、周月报告和洞察，等待新结果时显示加载；不得把旧币种金额误标为新币种。核对独立汇总、有效 R、未知纪律、样本量和无记录空状态。
11. 本周目标、盘前项目勾选/归档，重启后历史仍在，不自动改变交易事实。切换深色/系统主题及两种盈亏配色，图表/卡片一致；字体放大检查文字、触点与系统导航栏。
12. 通过系统 SAF 保存完整 ZIP，预览图片与全部新状态数量、二次确认后在测试数据上分别合并/覆盖，重启后逐张查看；重复合并不产生重复交易/图片。旧 V0.2–V0.7 JSON 恢复仍明确不含图片。
13. 在预览后新增一条测试记录/改变规则再确认，必须拒绝旧预览并要求刷新。取消预览不改本机；坏 ZIP、摘要错误、非法路径等副本应拒绝，原记录可读。
14. 在测试环境模拟存储不足/中断导出、切换后台或结束进程后重启。记录完整状态，不把不完整外部备份当成功；备份阶段不要在含重要数据的设备做破坏性试验。模拟器故障注入不等于手机已验证低空间/断电。
15. 如需测试 1000/5000/10000 记录，只导入本地合成数据；不要上传真实记录或图片。记录列表、统计、OCR、大 ZIP 的实际等待时间/内存问题，不把共享 CI 的数字当作手机承诺。
