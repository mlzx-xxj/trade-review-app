基线：V1.0 PR #9 已于2026-10-13合并，main f0323e38faeb002d2f18fbe3056733b2fded8022；独立分支codex/v200-rebuild，不自动合并。

2. 独立精确领域层：FIFO、普通A股T+1、期货多空和平今/平昨、按批次费用分摊、风险金/资金分离。缺失已核实参数拒绝自动计算；未知期初持仓须补录真实开仓。
3. 两账户、独立风险与策略、已核实合约规则；风险超限须确认，但不能篡改真实成交。
4. 五页紧凑导航与交易表单；首页只展示持仓及已实现结果，风险策略入口固定。
5. 标的计划及持仓周期复盘分别存储，价格/数量/费用事实不由复盘修改。
6. 双账户资金、周月统计；只按确认平仓交易日统计，图表精确刻度、零轴、触摸和滚动。
7. JSON新版本/ZIP、旧备份恢复、正式迁移、全部JVM及API29/35回归、独立验签和RC交付。

默认FIFO；每次平仓成交计一次已实现交易，跨批次匹配不重复计数。股票成交数量为整数股，普通证券仅T+1，无融资卖空、ETF/债券/T+0或公司行为自动调整。期货数量整数手，夜盘自然日期与人工确认交易日分别保留，不推断节假日。费用按累计匹配数量分摊至小数12位，最后一份吸收余数，确保原实际费用完整守恒，不重复扣除。

风险金不能当账户权益或现金。股票参考现金须期初资金及完整历史经用户明确确认；期货不伪造逐日盯市现金/权益。参考保证金只在参数核实时显示。合约“+0.01”必须选择元/手或成交额费率，无单位时拒绝启用。

保留原V0.3证书pin，不生成或读取长期私钥。可用签名未配置时只交付隔离RC，正式版待原签名和手机验收。
